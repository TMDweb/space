تثبيت wacli وربطه بمساعد ذكاء اصطناعي Install wacli & connect it to an AI agent

دليل مختصر خطوة بخطوة لتثبيت أداة wacli على الماك وربطها بـ Claude أو Codex، حتى يقدر المساعد يقرأ ويبحث ويرسل رسائل واتساب نيابة عنك.

ما هي wacli؟ أداة سطر أوامر (Command Line) تربط واتساب بجهازك وتخزّن محادثاتك في قاعدة بيانات محلية على الماك. أي مساعد ذكاء اصطناعي يقدر يشغّل أوامر في الترمنال (مثل Claude Code أو Codex) يقدر يقرأ هذه المحادثات ويبحث فيها ويرسل رسائل، بدون أي إضافة أو ربط خاص.

الوقت المتوقع: حوالي 5 إلى 10 دقائق. كل الأوامر تتنفّذ في تطبيق Terminal (الترمنال) على الماك.

المتطلبات Prerequisites

  • جهاز Mac يعمل بنظام macOS، مع تطبيق Terminal (موجود في Applications > Utilities).
  • هاتف فيه واتساب فعّال (لمسح رمز QR مرة واحدة).
  • مساعد ذكاء اصطناعي مثبّت في الترمنال: Claude Code أو OpenAI Codex. إذا ما كان مثبّتاً، ثبّته أولاً ثم ارجع للخطوة 6.
1

تثبيت HomebrewInstall Homebrew (the package manager)

Homebrew هو مدير الحزم الذي نثبّت من خلاله wacli. الصق هذا الأمر في الترمنال واضغط Enter:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

إذا طلب منك تثبيت Command Line Tools، وافق عليه (ضروري). أو شغّل هذا الأمر بنفسك:

xcode-select --install

بعد انتهاء التثبيت، أضف Homebrew إلى مسار النظام (PATH). هذه الخطوة مهمة على أجهزة Apple Silicon، وبدونها تظهر رسالة brew: command not found:

echo >> ~/.zprofile
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

للتأكد أنه ثبّت بنجاح: شغّل brew --version ويفترض يظهر رقم الإصدار.

2

تثبيت wacliInstall wacli

أمر واحد يثبّت الأداة من المستودع الرسمي:

brew install openclaw/tap/wacli

للتأكد: شغّل wacli --version.

3

ربط رقمك في واتسابLink your WhatsApp number

شغّل أمر المصادقة، وراح يظهر رمز QR داخل الترمنال:

wacli auth

من جوالك: افتح واتساب < الإعدادات < الأجهزة المرتبطة (Linked Devices) < ربط جهاز < امسح رمز الـ QR الظاهر في الترمنال.

بديل بدون كاميرا: الربط برقم الهاتف عبر wacli auth --phone 9665XXXXXXXX.

4

مزامنة الرسائلSync your messages

هذه هي الخطوة الرابعة المهمة: تنزيل محادثاتك إلى قاعدة البيانات المحلية حتى يكون عند المساعد شيء يقرأه. بدونها لا توجد رسائل ليطّلع عليها.

موصى به · Recommended

شغّل المزامنة المستمرة واتركها تعمل في نافذة ترمنال مفتوحة طوال الوقت:

wacli sync

طالما هذا الأمر شغّال، أي رسالة واتساب جديدة تُحفظ مباشرة في قاعدة البيانات، فيقرأ المساعد أحدث الرسائل. إذا أغلقت النافذة أو أوقفته (Ctrl+C)، تبقى في قاعدة البيانات الرسائل القديمة فقط حتى آخر مزامنة، ولن يرى المساعد أي رسائل أحدث حتى تشغّله من جديد.

بديل سريع لمرة واحدة: wacli sync --once يزامن ثم يتوقف. مناسب لو تبي تحديث سريع بدون ترك نافذة مفتوحة.

5

تأكد من الاتصالVerify the connection

تحقق أن الربط تم بنجاح:

wacli auth status

أو فحص شامل للحالة وقاعدة البيانات:

wacli doctor
6

اربطه بمساعد الذكاء الاصطناعيConnect it to an AI agent

الفكرة الأساسية: wacli مجرد أداة سطر أوامر على جهازك. أي مساعد يقدر يشغّل أوامر الترمنال يستخدمها تلقائياً، بدون أي إضافة (plugin) أو ربط خاص. كل ما تحتاجه أن تطلب منه بلغة عادية.

Claude Code / كلود

اكتب طلبك بالعربي أو الإنجليزي، مثل: «اقرأ آخر رسائلي مع سلمان في واتساب عبر wacli». أول مرة يشغّل فيها أمر wacli راح يطلب منك إذن (Access) للتنفيذ؛ وافق عليه. هذا هو طلب الصلاحية المقصود.

OpenAI Codex / كودكس

نفس الطريقة تماماً: اطلب منه قراءة واتساب عبر wacli، وعند تنفيذ الأمر راح يطلب الموافقة على تشغيله؛ وافق عليه. لأن كليهما يشغّلان أوامر الترمنال، فالأداة نفسها تعمل مع الاثنين.

اختياري وموصى به للفريق: علّم المساعد الأوامر الشائعة مرة واحدة بإضافتها لملف ذاكرته، حتى ما تكررها كل مرة. لـ Claude Code: ملف CLAUDE.md (داخل المجلد) أو ~/.claude/CLAUDE.md (عام). لـ Codex: ملف AGENTS.md. الصق هذا المقطع:

# WhatsApp via wacli
wacli is installed and authenticated on this Mac.
To read / search / send WhatsApp, use these commands:
- find a contact:  wacli contacts search "name"
- read a chat:     wacli messages list --chat <JID> --limit 50 --full
- search messages: wacli messages search "query"
- send a message:  wacli send text --to <JID> --message "text"
Run `wacli sync --once` first if the data looks stale.

أمثلة على الطلبات (example prompts):

read & summarizeاقرأ محادثتي مع لمى في واتساب ولخّص لي آخر 10 رسائل.
searchابحث في رسائلي عن كلمة «العقد» وأعطني الروابط.
send (asks before sending)أرسل رسالة لسلمان في واتساب: تم الانتهاء من التقرير.

حل المشاكل الشائعة Troubleshooting

تظهر رسالة brew: command not found
تخطّيت خطوة إضافة Homebrew للمسار في الخطوة 1. أعد تشغيل سطر eval "$(/opt/homebrew/bin/brew shellenv)"، أو أغلق الترمنال وافتحه من جديد.
يطلب تثبيت Command Line Tools
وافق عليه؛ هو ضروري لعمل Homebrew. أو شغّل xcode-select --install وانتظر انتهاء التثبيت ثم أعد المحاولة.
انتهت صلاحية رمز الـ QR قبل ما أمسحه
شغّل wacli auth مرة ثانية، وراح يظهر رمز جديد. امسحه بسرعة من خلال الأجهزة المرتبطة في واتساب.
المساعد يقول لا توجد رسائل أو البيانات قديمة
شغّل wacli sync --once لتحديث المحادثات، ثم اطلب من المساعد المحاولة مرة أخرى.
أريد فصل الحساب أو إعادة الربط
شغّل wacli auth logout ثم wacli auth لإعادة الربط من جديد.
